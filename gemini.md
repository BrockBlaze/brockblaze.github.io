# Project: brockblaze.github.io

This is a personal portfolio website for Brock Blazzard.

## Structure:
- The root `index.html` is the main landing page.
- `/pages`: Contains other HTML pages like `about.html`, `gallery.html`, etc.
- `/Games`: Contains various web-based game projects.
- `/Projects`: Contains other coding projects.
- `/styles`: Contains CSS stylesheets.
- `/js`: Contains JavaScript files for the main website.
- `/files`: Contains miscellaneous files like fonts and resumes.
